## Unreleased

### Current pending source work

- Added cross-platform Workspace notifications: React Bits Sound Lab Pluck on successful final settlement, and quieter Hint once per blocking Ask call. macOS uses `afplay`, Windows uses PowerShell with checked WinMM `PlaySoundW`, and Linux selects available PipeWire/PulseAudio/ALSA players without masking device failures. Windows rejects a FALSE native result and forbids default-beep fallback, replacing the initial SoundPlayer path that could hide backend failures. `/sounds` exposes session-only mute and preview controls; errors, late cancellation, passive browsing and noninteractive runs remain silent. Bundled portable 16-bit PCM WAVs carry original export and conversion provenance plus the upstream MIT + Commons Clause notice. Playback adds no npm dependency; Linux requires an installed player and audio output. Native Windows regressions cover accepted playback and rejected missing assets in the existing OS CI matrix.

- Centred Composer's single static ember mark in the five cells the scenes fill. It previously sat in the last of those cells, so the idle `○` beside `What's next?` hugged the label and left the marker block visually empty on its left; idle, waiting, finished, failed and stopped marks now share the working scenes' centre axis, and labels still begin in the same column.

- Replaced Composer's single comet with the five-scene living ember the contract documents: figure-eight for thinking, a four-lane conveyor for writing, twin counter-orbits for tools, corner collapse for compaction and a serpentine trail for generic working. One `dot()` writer snaps to the ten-by-four braille grid, drops off-canvas points and records per-cell heat, so rendering stays deterministic from elapsed run time with no timer, randomness or state write; static marks right-align inside the same five cells so moving and static labels share one column.

- Made the dictation suite portable after a Windows report and recorded the rule in `AGENTS.md`: `npm test` runs on the three-OS CI matrix, so tests must not hardcode an existing POSIX path (`/bin/sh` → `process.execPath`), a separator-bearing expectation (`join` in both the value and the expected string), or a bare path passed to native `import()` (`pathToFileURL`). The reported two failures hid three more, because the `/bin/sh` assertion aborted its test before later assertions ran; the guidance now names that masking and keeps independent platform-sensitive assertions separable.

- Added a project-local `/update` command in `.pi/prompts/update.md`: it records a baseline, updates the Pi host, reads the changelog and declaration diff against the previous release, reviews every host import and guarded native internal, refreshes the lockfile host and recorded version baseline, then runs the full pipeline plus an isolated cold load. Only `.pi/prompts/` and `.pi/README.md` are un-ignored; other `.pi` state stays out of Git.

- Added Composer microphone dictation as a new `dictation.ts` module: the fullscreen bottom rail carries a mic that captures through one `ffmpeg` child (avfoundation/dshow/PulseAudio or ALSA, 16 kHz mono, five-minute cap), shows `REC <n>s`, and inserts the local `whisper-cli` transcript at the editor cursor on the second click; `/dictate` is the keyboard path where pointer clicks cannot arrive or the rail is under 40 columns. The first use without a model asks once before a `.part`-streamed `ggml-base.en.bin` download (142 MB) whose SHA-256 is checked against the digest Hugging Face announces on its redirect; declining or failing writes nothing. Missing tools show `mic !` with a platform-specific hint. Recording is stopped with an interrupt because ffmpeg only reads `q` on a real terminal. Every child's stdio stream carries an error listener and spawn failures reject the start with the errno and the offending path, because an unhandled `error` event on a child or its stdin would otherwise take down the whole Pi process. Setup cancelled mid-confirmation or mid-download stops there: every continuation, progress callback and rejection is generation-guarded, so a stale download can neither start a recording nor reset a newer one, and a rejecting dialog is reported rather than escaping as an unhandled rejection. No npm dependency, no preference file, no `/workspace` room: `pi-composer.json` and `pi-workspace.json` are untouched, and neither editor wrapper lets the rail click take keyboard focus. Windows/Linux capture argv, device-hint classification and the download's integrity path are unit-tested; their real device paths and a spoken microphone pass remain manual.
- Reworked the Ask panel's controls: the keybind bar names the note action in every mode (**+ Note** for choices, **Tab Note** for free text), **Esc Close** and note-discard hints use the error tone, Escape is one deterministic close that shows a red **⚠ Discard N answers and M notes and close?** confirmation (empty forms close at once; Escape no longer clears a staged answer, which is now **Ctrl+C**), F2 More lists **Discard and close** and **Clear selection**, a session-only **Pinned** corner label collapses the panel to a one-line bottom bar that keeps the question, progress and dismiss visible while the transcript scrolls (posted overlays anchor bottom-center), and **Something else…** keeps a three-row capped editor pinned below a scrollable window of the earlier options with **Alt+Up/Down**. Ask previews still show only title/progress/body/hint hits.
- Added Windows/Linux/macOS CI at Node.js 22.23.2, npm 10.9.8 and Pi 1.3.0, plus a non-admin Windows Git Bash installation and interactive smoke-test guide. Loader fixtures use Windows junctions, path filters accept both separators, captures use unique OS temp directories, and only the unrepresentable newline-filename filesystem case is skipped on Windows. Footer shutdown waits for Git child handles to close; cleanup uses bounded retries. Packed-suite tests invoke npm/Pi JavaScript entry points without Windows shell-shim assumptions.

Documented an explicit user-keybinding alias and applied it in integration fixtures without weakening preservation assertions; a separate undecorated-editor regression reproduces the upstream failure and verifies recovery using the same history. No live keybindings or upstream Vim source are modified.
